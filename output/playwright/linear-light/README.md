# Linear 浅色数据提取样板

入口：http://127.0.0.1:5174/?template=ui

仅供确认数据提取页的布局与样式。结果为合成示例，尚未接入真实提取流程。

## 设计方向

- 产品：面向工程人员的模块和芯片测试数据提取工具。
- 气质：克制、精确、紧凑。
- 场景：工程数据工作台。
- 重点：白色结果表，主按钮使用少量靛蓝色。
- 特征：灰阶导航、浅灰配置区、固定位置的字段和单位。

参考：[Linear 官方设计说明](https://linear.app/now/how-we-redesigned-the-linear-ui)。借鉴其浅色灰阶、导航层次与低装饰界面；并非逐像素复刻。

## 与上一版的差异

上一版的三处问题：大面积绿色选中背景竞争注意力；配置与表格都有卡片边框和阴影；结果工具栏分为两行且重复显示标题与数量。

- 保留左侧配置、右侧表格。
- 配置区使用浅灰背景，取消卡片外框与阴影；组间用细线和间距区分。
- 移除绿色多选底色，使用灰色复选框和普通文字。
- 表格标签、记录数与搜索合为一行。
- 配置控件高 30px，运行按钮高 32px，数据行高 36px。
- 复用现有 shadcn/Radix、Lucide、本地字体；没有新增依赖。
- 样板样式位于 `web/src/prototypes/linear-light-template.css`，限定于数据提取页。

20ui：重点应用 R02、R03、R04、R06、R09、R13、R19、R20。
unslop：按间距、颜色、图标、文案、字体、布局、细节、视觉、动效顺序检查；没有新增装饰图片或动画。

## 验证

- TypeScript + Vite 构建通过。
- 本次样板 TSX 的 ESLint 检查通过。
- Playwright：配置折叠/展开、下拉菜单退出、空条目禁用运行、重复运行与取消、搜索无结果与清除、分页、结果标签、异常记录为空、读取失败、首次使用通过。
- 1440×960、1366×768、1024×768：左右布局成立；配置底部约 676px，全部配置控件与运行按钮均在首屏；页面无横向溢出。
- 390×844：上下布局；示例配置与运行按钮在首屏；页面无横向溢出，表格内部允许横向滚动。
- 首屏检查使用两条示例条目。长条目列表仍在文本框内部滚动。
- 主按钮白字/靛蓝底对比度约 5.53:1；标签文字/配置底色约 6.07:1；表头文字/表头底色约 5.32:1。只检查这些配色组合，不代表完整无障碍审计。
- 未验证：真实提取、Electron 打包、Windows。
