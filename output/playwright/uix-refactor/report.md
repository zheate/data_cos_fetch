# uix 原生界面重构

日期：2026-11-13，Asia/Shanghai。

## 交付范围

保留 MyGo 原生 Go 界面与 Rust 提取引擎，增加固定版本 `github.com/smallnest/uix v0.2.3`。当前 MyGo 仍为 `v0.9.1-0.20261113060250-614ea7a6af6e`，没有降级。

本次没有修改 Rust 提取规则或旧版 Web 文件。默认启动仍为 `npm start`，本机应用包位于 `native/build/darwin-arm64/Data COS Suite.app`。

## 控件与布局

| 区域 | uix 组件 | 行为 |
| --- | --- | --- |
| 编号／完整路径 | textarea、button | 大输入区、编号计数、导入、按原顺序整理去重、清空后保持焦点 |
| 电流点 | input、field、button | 最大值／全部快捷设置；就地校验；无效输入禁用提取 |
| 测试站别 | checkbox、button | 两列、32 DIP 整行点击、键盘 Space 切换、全选／清空 |
| 提取按钮 | button.Primary | 固定可见、44 DIP、Ctrl／Command + Enter、忙碌时禁用重复提取并提供取消 |
| 结果区 | table、searchfield、segmented、empty | 全高虚拟表格、固定一致的十列表头、数值排序、多选、搜索和空状态恢复 |
| 分栏 | split | 拖动调整宽度；保留 MyGo 的分隔条键盘操作与双击复位 |

主题从 uix 设计令牌派生，保留现有蓝色重点色。公共图标动作改用 uix Ghost 按钮，并保留中文悬停说明和可访问名称。窗口、布局容器与可放置内容的对话框继续使用 MyGo 原生能力。

原有自定义站别弹窗直接写入配置。现在编辑独立草稿，只有「保存站别」才应用；取消、Escape、点击外部均丢弃草稿。

结果选择按编号、站别、电流组成的身份保存，排序不会把选择切换到其他记录。复制图标说明当前复制范围。表格内 Ctrl／Command + C 复制选中记录；右键支持单元格、此行和筛选结果复制。复制与 CSV 共用源数值格式，避免显示三位小数后丢失精度。

## 检查与结果

- uix 的 textarea、input、checkbox、button、table、split、segmented 上游测试，在本项目 MyGo 依赖组合下通过。
- `npm run test:mygo` 通过：Go 竞争检测、全部本项目测试、`go vet`。
- `go tool mygo vet .` 通过：原生 UI 生命周期检查。
- `npm run test:mygo:e2e` 通过：14 项真实窗口检查，详见 `native-e2e.json`。
- 真实窗口类型为 MyGo 原生 `content`。模块模式 4 个测试编号提取 12 条 LVI／Rth 合并记录；芯片模式提取 3 条记录。
- 真实测试 Excel 的最大电流、全部电流、指定电流，以及两种模式的 lambd 提取检查通过。
- 原生界面检查覆盖 1440×900、1000×720 和深色模式。编号、电流、站别、提取按钮、结果区域的可见边界检查通过。
- 站别点击区域不少于 32 DIP；编号输入高度不少于 140 DIP；结果区保留窗口高度减 120 DIP 以上。
- 中文文本、编号整理、输入焦点快捷键、电流校验、取消、站别草稿保存与丢弃检查通过。
- 结果多选、数值排序后的选择保持、精确复制、搜索快捷键、右键菜单、Escape 清除选择检查通过。
- 10000 条记录场景通过表格检查，可访问树中的行元素不超过 50 个。未做批次耗时或内存基准测试。
- 长无效电流输入原先将提取按钮挤到 y≈740。回归测试暴露该问题后，将行内错误限制为一行，并保留悬停全文与辅助技术错误说明。回归检查通过。
- 配色抽查：次要文字 `#62626b` 在输入背景 `#f4f4f5` 上约 5.49:1，在选中站别背景 `#e9e9ec` 上约 4.98:1；白字在主要按钮 `#2459bd` 上约 6.48:1；深色次要文字在悬停背景上约 4.98:1。仅检查这些正常状态组合，不等于完整无障碍审计。
- `git diff --check` 与 Node 启动脚本语法检查通过。
- `npm run build:mygo` 通过，生成约 18.6 MB 的 macOS arm64 应用包。`codesign --verify --deep --strict` 通过。应用包启动后进程检查通过；未公证、未发布。
