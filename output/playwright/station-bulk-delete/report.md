# 站别批量删除

最终入口：在「新增站别」右侧显示中文「删除」按钮，一次删除所有勾选的站别。删除按钮没有悬停提示；站别不再有悬停提示或右键菜单。

沿用现有紧凑、准确、安静的数据工作台方向及 MyGo/uix 控件。布局、字体和颜色沿用既有样式，仅修改站别操作入口。

## 修改

- 常用站别和新增站别统一参与批量删除。先取得选中名称的快照，再移除配置，未勾选项不变。
- 没有勾选或提取期间禁用删除；操作函数也检查这两个条件。
- 已选数量、列表与提取范围同步更新。删除状态继续随配置保存，全选不恢复删除项。
- 保留原始测试文件和已有提取结果。删除最后一项时显示新增提示并禁用模块提取。
- 删除右键菜单和两处站别 Tooltip 声明，也移除新增按钮的 Tooltip。控件保留中文可访问名称与键盘焦点。

## 验证

- `npm run test:mygo`：通过，包含竞争检测、原生界面与引擎检查、`go vet`。
- 原生界面测试：浅色与深色，1000×720、1440×900；320 DIP 最小侧栏宽度下，「删除」仍位于「新增站别」右侧且不溢出。
- 批量删除检查：选中与未选中混合、两类站别、重复操作、忙碌禁用、键盘空格触发、删除最后一项、重新添加、无右键菜单与无站别提示描述。
- `npm run test:mygo:e2e`：19 项通过。真实原生窗口删除一个常用站别和一个新增站别，保留未勾选项；勾选剩余站别后，真实 Rust/Excel 数据提取得到 12 条记录。见 `native-e2e.json`。
- `go tool mygo vet .`、`git diff --check`：通过。
- `npm run build:mygo`：通过，生成 macOS arm64 应用，签名校验通过。
