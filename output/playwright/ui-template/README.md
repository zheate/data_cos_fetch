# 数据提取布局样板

最新版本：保留左侧配置、右侧结果表。当前验证见 [紧凑侧栏说明](compact-sidebar.md)，当前截图为 `data-fetch-compact-sidebar-1440.png`。下文保留初版记录。

这是供确认布局的独立预览，不是正式业务重构。

启动：`npm --prefix web run dev -- --host 127.0.0.1`，访问终端所示地址并附加 `?template=ui`。
本次预览服务：http://127.0.0.1:5174/?template=ui 。默认打开数据提取。

## 设计方向

- 产品：供工程人员按条目提取模块或芯片测试数据。
- 气质：克制、精确、紧凑。
- 场景：测试数据表和工程工作台。
- 重点：解析明细表；COS 辅助页使用波长分布图。
- 特征：数值右对齐，单位留在表头，操作与状态留在固定位置。

## 基准与主要修改

基准：`before-1440.png`，1440 × 960，数据提取初始配置页。
样板：`data-fetch-1440.png`，同视口，示例结果状态；两个截图的内容状态不同，用于比较页面组织，不构成相同业务状态的完整回归。

- 20ui R04 / R06：移除占据整列的全局导航，顶部切换数据提取/COS 筛选。运行演示留在左侧配置区底部。
- 20ui R08 / R09：来源、条目、文件类型、电流点、站别集中在同一配置列，右侧保留宽结果区。
- 20ui R03 / R12 / R15：摘要不使用独立卡片和装饰图标；表头标明单位；数值右对齐；错误状态有文字与恢复入口。
- unslop：中性背景、单一青绿色重点、原有字体与 Lucide 图标；复用现有 Button/Input/Checkbox/Textarea。无新增依赖。无装饰动画。

## 验证

- TypeScript + Vite 生产构建通过。
- 本次修改的 TSX 文件 ESLint 通过。
- Playwright：搜索无结果、按站别搜索、清除搜索、取消、再次运行完成、读取失败、首次使用、异常记录空状态通过。
- 1440 × 960、1024 × 768、390 × 844：页面无横向溢出。小屏数据表可以内部横向滚动。
- COS 辅助页面：分页、配置折叠、详情展开/关闭完成交互检查。
- 宽屏运行按钮位于首屏；左侧长配置区单独滚动。
- 截图覆盖：桌面与窄屏数据提取页面。
