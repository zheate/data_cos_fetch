# 数据提取：紧凑侧栏样板

按用户截图保留左侧配置、右侧结果表。只修改预览样板，不替换正式页面。

- 删除重复副标题、数据来源介绍、模块说明行、大块统计区和默认解释文字。
- 保留字段名称、单位、六个站别、错误提示和示例数据标识。
- 配置输入框高 32px，条目框高 64px，站别分两列；主要间距为 8px / 12px。
- 右侧表格与配置区顶部对齐。表格行高 36px。

## 验证

- `npm --prefix web run build` 通过。
- 本次 TSX 的 ESLint 检查通过。
- Playwright 检查：1440×960、1366×768、1024×768，配置控件和运行按钮全部在首屏；左右布局成立；页面无横向溢出。
- 配置底部位置：1440 / 1366 宽窗口约 665px；1024 宽窗口约 661px。
- 配置折叠/展开、站别勾选、取消演示、读取失败状态通过。
- 390×844：页面无横向溢出，小屏按上下布局滚动，不承诺所有配置首屏可见。
- 长条目列表可以在文本框内部滚动；上述首屏检查使用两条示例条目。
- 未验证真实提取、桌面打包或 Windows。
