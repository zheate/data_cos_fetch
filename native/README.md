# MyGo 数据提取

MyGo 原生 Go 界面使用 uix v0.2.3 组件，直接调用 Rust 提取引擎。没有 HTML、JavaScript 界面、Electron 或 HTTP 服务。

## 运行

在仓库根目录运行：

```sh
npm run bootstrap
npm start
```

需要 Node.js、Cargo 和 Go 1.27.4+。macOS arm64 缺少 Go 时，启动脚本会校验并解压项目内的 Go 工具链到 `.tmp/toolchains/`，不修改系统安装。其他平台先安装 Go，或设置 `DATA_COS_GO`。

```sh
npm run build:mygo
npm run test:mygo
npm run test:mygo:e2e
```

`build:mygo` 使用 MyGo CLI 打包本机平台，将 Rust 提取引擎放入平台资源中。macOS 输出位于 `native/build/darwin-arm64/`。构建不执行发布或上传。

`test:mygo` 构建 Rust 提取引擎，运行 Go 竞争检测、真实 Excel 文件提取、原生界面交互及 `go vet`。原生界面检查覆盖 1440×900 和 1000×720。旧版 Electron 仍可以使用 `npm run start:electron`。

`test:mygo:e2e` 使用仅测试构建导入的 MyGo 自动化插件运行真实原生窗口，结束时关闭本次窗口和进程。截图与记录默认写入 `output/playwright/uix-refactor/`；`DATA_COS_UI_OUTPUT` 可以指定本次检查的输出目录。

## 使用

1. 选择模块或芯片模式。
2. 设置数据根目录，或直接输入完整路径。
3. 每行输入一个编号，选择测试文件和测试站别。
4. 输入电流点，点击「开始提取」。
5. 在结果表中搜索、排序、调整列宽或横向滚动。
6. 用「导出结果」导出 Excel 或 CSV。

左侧按编号、电流点、测试站别、提取按钮的顺序排列。编号输入框保持紧凑高度，长清单在框内滚动；测试站别列表占据剩余高度，内容超出时独立滚动；提取按钮固定在左侧底部。右侧结果表占满可用高度。中间分隔条支持拖动调整宽度。数据根目录与测试文件类型收在右上角设置中。

电流留空表示各文件最大电流，`a` 表示全部电流，支持 `2, 4, 8~12`。整数范围逐点展开；小数范围保留两端，与旧版规则相同。

「最大值」与「全部」可以直接设置电流。无效电流会在输入框下方提示，并禁用提取。站别采用整行点击区域；自定义站别只有点击「保存站别」才写入配置，取消和 Escape 丢弃草稿。

「新增站别」打开自定义站别清单。保存后，名称直接加入主界面的站别列表，默认勾选。新增站别与常用站别共用同一复选框，支持鼠标、空格键、全选和清空；只提取勾选的站别。自定义站别的勾选状态随配置保存。站别较多时列表独立滚动，长名称用省略号显示。

勾选站别后，点击「新增站别」右侧的「删除」，一次删除全部勾选的站别。没有勾选或提取期间，删除按钮禁用。站别、增加和删除按钮不显示悬停提示，也不提供站别右键菜单。删除只移除站别配置，不删除测试文件或已有提取结果。删除状态随配置保存；全选不会恢复删除的站别，可以通过「新增站别」重新添加。

「整理编号清单」移除空行和重复编号，保留原始顺序。结果表支持按住 Ctrl／Command 多选、Shift 连选、按数值排序以及右键复制单元格。复制图标的悬停名称会说明当前复制的是选中记录还是筛选后的记录。

快捷键：Ctrl／Command + Enter 提取；+ L 聚焦编号；+ F 聚焦结果搜索；表格内 + C 复制选中记录；表格内 Escape 清除选择。

模块编号的路径规则保持不变：编号按字符拆成多级目录。包含路径分隔符的输入直接视为路径。芯片模式保留 `postQCW` 和年月目录查找规则。

导出包含本次全部记录，搜索只影响界面和复制。Excel 使用数值单元格保存引擎返回的数值，附带「提取提示」工作表。Excel 与 CSV 导出不额外舍入。界面中的数值显示三位小数。

配置与旧版隔离，保存在系统配置目录下的 `data-cos-suite-mygo/settings.json`。结果只保存在内存中。`DATA_COS_SETTINGS_PATH` 可以覆盖配置路径；`DATA_COS_EXTRACT_BIN` 可以指定提取引擎。

## 架构

- `view.go`：uix 输入框、复选框、按钮、分栏、虚拟表格；MyGo 原生容器和对话框。
- `controls.go`：uix 主题、公共控件样式和复制反馈。
- `app.go`：任务快照、取消、结果状态、搜索和排序。
- `model.go`：输入校验、电流解析与配置保存。
- `engine.go`：子进程生命周期及 JSON 协议。
- `export.go`：复用 Excelize 导出 Excel；标准库导出 CSV。
- `../rust/crates/data-cos-data-adapter/src/bin/data-cos-extract.rs`：只接收一次提取请求的 Rust 程序。

按钮统一经 `controls.go` 的 `workbenchButton` 创建。uix v0.2.3 的自绘按钮背景带圆角，但未设置元素圆角；封装用同一主题圆角修正边框与键盘焦点环，避免次要按钮出现直角边线。

MyGo 固定到 `614ea7a6af6e` 对应的模块版本。自动化插件只在 `e2e` 构建标签下导入，不进入普通构建。原有 Rust 数据规则和旧版前端保持独立。

uix v0.2.3 声明的最低 MyGo 版本为 v0.4.5。本项目保留当前 MyGo 版本；所用输入框、按钮、复选框、表格、分栏、分段控件的上游测试，以及本项目检查均在该依赖组合下运行。

UI 设计使用 unslop by Damir Sokolovsky（[@heydamir](https://x.com/heydamir)）的检查方法，遵循 CC BY 4.0 署名要求；图标沿用 Lucide（ISC）。
